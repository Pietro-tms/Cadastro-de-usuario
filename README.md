# Cadastro de Usuário

Aplicação desenvolvida com React para simular o cadastro de usuários por meio de uma interface simples e intuitiva. O projeto foi criado com foco na prática de conceitos fundamentais do desenvolvimento front-end, incluindo componentização, gerenciamento de estado e manipulação de formulários.

Atualmente, a aplicação consiste apenas na interface do sistema e não possui integração com APIs ou bancos de dados. Dessa forma, os dados inseridos não são armazenados permanentemente e são perdidos ao recarregar ou encerrar a aplicação. O objetivo principal do projeto é exercitar a construção de interfaces e o fluxo de entrada de dados utilizando React.
