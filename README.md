# Cadastro de Usuários

Aplicação em React para cadastrar, listar e excluir usuários em uma interface simples.

## Funcionalidades

- Cadastro com nome, e-mail e idade
- Exibição dos usuários cadastrados
- Exclusão de usuários da lista

## Tecnologias

- React
- JavaScript
- CSS
- Vite

## Como executar

```bash
git clone https://github.com/Pietro-tms/Cadastro-de-usuario.git
cd Cadastro-de-usuario
npm install
npm run dev
```

Abra no navegador o endereço exibido pelo Vite.

## Observação

Os dados ficam apenas na memória do navegador. O projeto ainda não possui integração com API ou banco de dados, então os cadastros são perdidos ao recarregar a página.
